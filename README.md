# Descripción

MateoVenturas es un videojuego 2D desarrollado en Unity donde el jugador debe avanzar por distintos niveles, superar obstáculos, recoger frutas y enfrentarse a enemigos inspirados en una aventura de plataformas clásica.

El protagonista está inspirado en Mateo y la temática general gira en torno a dinosaurios y exploración.
